Backpack and Spears Repositionner
Version 1.0.0

IED Node Overrides profile packaged for installation with Vortex.

Requirements:
- Immersive Equipment Displays (IED)
- Any spear mods referenced by the profile, including NewArmoury.esp and
  SkyrimSpearMechanic.esp, when their corresponding rules are used.

Installation:
1. In Vortex, choose "Install From File" and select the ZIP archive.
2. Enable and deploy the mod.
3. In IED, open the Node Overrides profile menu and load
   "Backpack and Spears Repositionner".

Source:
- Created from the local IED Node Overrides profile named "Custom".
